This project was created to solve a common commuter problem: missing destination stations due to fatigue or distraction. The app uses location-based logic to notify users before arrival so they can travel with less anxiety and better timing confidence.

As Mobile Developer, I implemented destination selection, geofence-based triggers, and alert behavior designed for quick setup in real travel conditions. The hypothesis was straightforward: if alert setup is simple and destination tracking is reliable, missed-stop incidents should decrease.

I reviewed commuter journey patterns, tested route scenarios with variable connectivity, and validated alarm timing behavior under practical constraints. GPS variability and battery impact were recurring challenges, which shaped a reliability-first scope for the initial release. The project improved my ability to design location-driven mobile features that balance technical precision with everyday usability.
