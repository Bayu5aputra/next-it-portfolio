I built an IoT-based emergency button system to reduce delay in incident detection and make escalation more reliable. The solution connects ESP32 hardware to a Laravel API and a real-time dashboard so operators can see urgent events as soon as they occur.

My role covered device integration, backend event handling, and dashboard delivery. I translated the core operational problem into a simple hypothesis: if emergency reporting is triggered automatically from hardware and displayed instantly in a central interface, response initiation becomes faster and more consistent than manual reporting.

To validate the design, I mapped operator needs, defined critical event fields such as location and timestamp, and tested repeated triggers, reconnect behavior, and end-to-end delivery from device to dashboard. The main constraints were WiFi stability and false triggers, so reliability safeguards were prioritized over feature expansion. This project strengthened my end-to-end thinking across firmware, API, and operational monitoring, and provides a solid base for future enhancements such as acknowledgement flows and multi-channel notifications.
