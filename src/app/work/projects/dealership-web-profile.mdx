ShowPro was developed as a dealership profile platform that combines public catalog visibility with secure internal management. The objective was to simplify listing updates and reduce inconsistency in product information.

As Web Developer, I built MVC modules, authentication flow, and admin-side CRUD operations while keeping the public-facing experience responsive. The guiding hypothesis was that role-based content management would accelerate update cycles and improve data consistency compared with manual page edits.

I mapped operational requirements from dealership workflows, designed a streamlined publish flow, and validated login, access boundaries, and data handling through functional testing. The main tradeoff was feature breadth versus maintainability, so core operational reliability was prioritized in the first release. This project sharpened my skills in secure web CRUD architecture and practical product delivery with business constraints.
