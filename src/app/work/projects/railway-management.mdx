Railway Management Application was built to centralize schedule, route, station, and operational data in one web system. The project objective was to reduce fragmented administration and improve consistency in railway operational records.

As Full Stack Developer, I implemented backend modules, relational data handling, frontend interfaces, and access control mechanics. The hypothesis was that bringing core entities into a structured, role-aware platform would improve planning accuracy and reduce manual coordination overhead.

I mapped entity dependencies, designed data flows around real admin tasks, and tested validation and integrity across core CRUD processes. The main constraint was handling complex relationships without framework abstraction, so architecture discipline was critical. This project strengthened my ability to design practical data-driven systems with predictable operational behavior.
